## 프로젝트 개요

시스템의 자원 사용량을 실시간으로 시각화하는 대시보드 프로젝트를 시작했습니다.
주로 서버의 CPU, Memory, Disk I/O를 모니터링하는 데 중점을 둡니다.

### 주요 기술 스택
- **Frontend**: React, TypeScript
- **Visualization**: D3.js, Chart.js
- **Backend**: Node.js (Express)
- **Data Source**: Prometheus API

앞으로의 개발 과정을 이 블로그를 통해 공유할 예정입니다.
